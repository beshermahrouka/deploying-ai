# Chatbot with Weather, Semantic Search, and Time Info Services

This project implements a chatbot using Python with Gradio for the user interface and integrates OpenAI's GPT models for natural language understanding and generation. The chatbot offers three main services:

1. **Weather Summary Service:**  
   It extracts city names from user input and fetches the current weather data (temperature and wind speed) using the Open-Meteo API. The weather info is then summarized into a friendly, conversational message using an OpenAI GPT chat completion.

2. **Semantic Search Service:**  
   Utilizing Chroma semantic search and OpenAI embeddings, this service allows the chatbot to answer user queries by searching a small knowledge base of documents (about biology, geography, technology, and data). The most relevant documents are retrieved using semantic similarity, and then their content is summarized as an answer by the GPT model.

3. **Time Information Service: Function Calling**  
   The chatbot can provide the current local time for selected cities by calling a Python function integrated through OpenAI’s function-calling feature. This uses the `pytz` library to get accurate timezone-aware timestamps.

## Key Components

- **Gradio UI:**  
  Provides a chat interface where users can type messages and get bot responses.  
- **OpenAI GPT Model ("gpt-4o-mini"):**  
  Powers language understanding, generation, summarization, and function calling.  
- **ChromaDB:**  
  Manages vector embeddings for semantic search capabilities.  
- **Open-Meteo API:**  
  Free weather information API used for fetching current weather data.  
- **Function calling:**  
  Integrated OpenAI feature to call Python functions (e.g., to fetch time information).

## Guardrails

To keep the chatbot safe and focused, a list of **forbidden topics** is implemented. If the user mentions any of these topics (`cats`, `dogs`, `horoscopes`, `zodiac`, `taylor swift`) in their input, the chatbot politely refuses to engage on those topics and asks the user to inquire about something else. This helps prevent off-topic or potentially sensitive conversations.

## How It Works

- User input is processed to check for forbidden topics first.
- Then keyword-based routing directs the query to one of the three main services (weather, semantic search, or time).
- For unknown cases, the chatbot uses OpenAI function-calling to try and call the appropriate helper function.
- Conversation history is maintained for context in the chat.
- Responses generated by the GPT model are friendly, concise, and natural.

## Usage

Run the script, and a Gradio web interface will launch. You can ask about:

- Weather in cities like Toronto, Vancouver, Montreal, Calgary, Ottawa.  
- General knowledge questions answered by semantic search (e.g., plant photosynthesis).  
- Current time in listed cities (Toronto, New York, London, Paris).

Try avoiding the forbidden topics to get meaningful answers.
